StockSpot Documentation

StockSpot is a real-time inventory alert system for Shopify. This guide walks you through install, setup, and the core concepts you need to know.

New here? Jump straight to the quickstart for a 5-minute setup, or view the product page for an overview.

Install

StockSpot installs in one click from the Shopify App Store:

  1. Open your Shopify admin.
  2. Navigate to Apps → Shopify App Store.
  3. Search for StockSpot by SOAR and click Add app.
  4. Approve the OAuth permissions when prompted. StockSpot requires read access to products, inventory, and locations.
  5. You'll land on the StockSpot dashboard. Welcome!

Quickstart

Here's the fastest path from install to your first alert:

1. Set your default threshold

In the dashboard, click Settings → Default threshold. Enter the stock level you want alerts fired at. For most stores, 5 is a reasonable starting point.

Default threshold: 5 units
Scope: all tracked products
Alert type: Low stock

2. Connect an alert channel

Go to Alerts → Channels. Add at least one of:

  • Email: enter one or more email addresses
  • Slack: connect your workspace via OAuth and pick a channel
  • SMS: add phone numbers (Growth plan and up)

3. Pick products to track

By default StockSpot tracks all products. To scope down, go to Products → Filters and set:

  • Collections (e.g., only Bestsellers)
  • Product tags (e.g., only products tagged priority)
  • Vendors or product types
Tip: StockSpot's smart defaults analyze your past 30 days of sales velocity and suggest thresholds per SKU. Click Suggest thresholds in the Settings page.

Thresholds

A threshold is the inventory level at which StockSpot fires an alert. StockSpot supports four kinds:

  • Global: one number for every tracked product.
  • Per-product: override the global for a specific product.
  • Per-variant: override the product-level for a specific SKU.
  • Per-location: track stock separately for each Shopify location.

More specific thresholds always win. If a variant has its own number, it uses that. Otherwise it falls back to the product level, then the global.

Alert channels

StockSpot can deliver alerts via:

  • Email — all plans. HTML or plain-text format.
  • Slack — all plans. Pick a channel, optionally thread by product.
  • SMS — Growth and Plus. International numbers supported.
  • Webhooks — Plus plan. Send a POST to any URL.

You can route different products or thresholds to different channels using rules.

Rules & filters

Rules let you say "when this condition is true, send this alert to this channel." Example:

Rule: "Bestsellers low stock to Slack ops"
When: inventory < 10 units
Where: collection = "Bestsellers"
Alert: #ops-stockouts in Slack
Frequency: at most once per hour per SKU

Multi-location

If your Shopify store has multiple locations (warehouse, retail, 3PL), StockSpot tracks each independently. Options:

  • Per-location thresholds: alert when any single location dips.
  • Rolled-up stock: sum across all locations and alert on the total.
  • Location-specific channels: route alerts for your Toronto warehouse to one Slack channel, Austin to another.

Webhooks

On the Plus plan, every alert can POST to a URL you control. Payload shape:

{
  "event": "stockspot.alert.low_stock",
  "created_at": "2026-10-28T14:00:00Z",
  "shop": "yourstore.myshopify.com",
  "product_id": 123456789,
  "variant_id": 987654321,
  "sku": "AF-001-32-TEAL",
  "title": "AquaFlask Bottle 32oz / Teal",
  "inventory": 2,
  "threshold": 5,
  "location_id": 1,
  "location_name": "Main Warehouse"
}

REST API

Plus plan includes a REST API at https://api.soar.studio/stockspot/v1. Endpoints:

  • GET /alerts — list recent alerts
  • GET /thresholds — list configured thresholds
  • POST /thresholds — set a threshold
  • GET /products — list tracked products

Auth is via API key — generate one from Settings → API.

Integrations

StockSpot has native integrations with:

  • Slack — all plans
  • Microsoft Teams — Growth and Plus
  • Zapier — Plus (3,000+ app connections)
  • Make.com — Plus
  • Google Sheets — Growth and Plus (auto-export reports)

Troubleshooting

I'm not getting alerts

  1. Check Alerts → Delivery log to see if alerts were sent.
  2. Verify the email didn't land in spam. Whitelist alerts@soar.studio.
  3. Confirm the Slack integration is still authorized (reconnect under Channels).
  4. Check thresholds — the inventory may actually be above your threshold.

Alerts fire too often

Set a debounce window in Settings — StockSpot will send at most one alert per SKU per time window (default 1 hour).

Still stuck? Email support@soar.studio with your Shopify store URL and we'll look into it, usually same business day.
