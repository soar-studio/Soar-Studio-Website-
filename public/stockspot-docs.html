StockSpot Documentation

StockSpot is a store-locator and multi-location fulfillment app for Shopify. It shows customers which of your stores has a product, lets them pick pickup / delivery / transfer, and routes the order to the right location — all from the product page.

New here? Jump to the quickstart for a 10-minute setup, or view the product page for an overview.

Install

StockSpot installs in one click from the Shopify App Store:

  1. Open your Shopify admin.
  2. Navigate to Apps → Shopify App Store.
  3. Search for StockSpot by SOAR and click Add app.
  4. Approve the OAuth permissions. StockSpot needs read access to products, inventory, locations, and orders — and write access to tag orders by fulfillment type.
  5. You'll land on the StockSpot dashboard. Your Shopify locations are already synced.

Quickstart

The fastest path from install to live widget:

1. Review your locations

Go to Locations. StockSpot pulled every Shopify location — confirm hours, address, phone, and whether each store accepts pickup / delivery / transfers.

2. Enable the theme widget

Open your Shopify theme editor → Product page → Add block → StockSpot: Store availability. Drop it under the Add-to-Cart button.

Theme → Customize → Product
→ Add block → StockSpot: Store availability
→ Save

3. Test it live

Visit any product page on your storefront, enter a postcode, and the widget will show which locations have the product and the available fulfillment options.

Tip: Preview the widget first in a draft/duplicate theme before enabling on your live store.

Locations

Each location you have in Shopify (POS, warehouse, 3PL) can be independently configured in StockSpot. For every location set:

  • Display name (what customers see on the widget)
  • Address, map coordinates, phone
  • Store hours (per weekday)
  • Fulfillment types enabled: pickup / delivery / transfer-from
  • Lead times: how long until pickup is ready, how long for transfers
  • Public/hidden: hide warehouse-only locations from the finder

Theme widget

The storefront widget is a Shopify Online Store 2.0 app block. Options you can set in the theme editor:

  • Position: inline on PDP, modal on click, or sidebar drawer
  • Lookup method: postcode, geolocation, or map pin-drop
  • Max locations shown: default 5
  • Default radius: 25 km / 15 mi
  • Fallback: what to show if no in-stock location in range

Live inventory

StockSpot reads inventory in real-time via Shopify's Inventory API. There's no sync delay — the moment stock changes in Shopify, the widget reflects it.

Supported inventory states:

  • In stock (available > threshold)
  • Low stock (available > 0 but ≤ threshold — threshold is per-product configurable)
  • Out of stock (available = 0 — shows transfer option if enabled)

Click & collect

When a customer picks "Pick up at this store":

  1. Checkout runs normally (no shipping charge, pickup address auto-filled).
  2. Order is created and tagged stockspot-pickup plus the location handle.
  3. Inventory is reserved at the chosen location.
  4. Customer gets a pickup-ready email with store hours, address, and a pickup PIN.

Store staff can mark the order picked up from Shopify admin or POS — this fulfills the order and releases the inventory reservation.

Local delivery

Local delivery lets you fulfill orders from a specific store for customers in a defined zone.

Define zones per location:

  • By postal/zip code list
  • By radius (e.g., 10 km around the store address)
  • By custom polygon drawn on a map

Customers in-zone see a "Local delivery" option. StockSpot picks the closest in-stock location automatically.

Store transfers

If the customer's nearest store is out but another location has stock, StockSpot offers a transfer:

Transfer flow:
Customer chooses "Transfer to [nearest store]"
→ Order created, tagged "stockspot-transfer"
→ Pick-list sent to the source location
→ Source packs & ships to destination
→ Destination notifies customer on arrival

Set per-location transfer times under Locations → Transfer settings. Transfers can be fulfilled via your own couriers, Shopify Shipping, or a third-party integration.

POS integration

On the Plus plan, StockSpot integrates natively with Shopify POS:

  • Pickup orders appear in POS as "To pick up today" lists.
  • Transfer requests show as inbound/outbound pick lists per store.
  • Mark picked up / transferred directly from the POS tablet.

REST API

Plus plan includes a REST API at https://api.soar.studio/stockspot/v1.

  • GET /locations — list configured locations
  • GET /availability?product_id=X&postcode=Y — live availability lookup
  • POST /pickup-orders — create a pickup order programmatically
  • POST /transfer-requests — initiate a store transfer

Webhooks

Subscribe to StockSpot events:

Events:
  stockspot.pickup.created
  stockspot.pickup.ready
  stockspot.pickup.collected
  stockspot.transfer.requested
  stockspot.transfer.arrived
  stockspot.delivery.scheduled

Troubleshooting

Widget doesn't show on PDP

  1. Confirm the StockSpot: Store availability app block is added to your product template and saved.
  2. Make sure the product is tracked in StockSpot (check Products in the dashboard).
  3. Clear your theme preview cache.

No locations shown for a postcode

Check your widget's default radius setting. The customer's postcode may be outside all location radii — StockSpot shows a fallback message in that case.

Still stuck? Email support@soar.studio with your Shopify store URL and the product you're testing. We usually reply same business day.
