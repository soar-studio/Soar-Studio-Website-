SmartCart Documentation

SmartCart is an in-cart upsell and conversion toolkit for Shopify. This guide covers install, configuration, and the advanced features that drive real AOV gains.

New here? Start with the quickstart to go live in 5 minutes, or view the product page for a feature overview.

Install

SmartCart ships as a Shopify Online Store 2.0 app with an embedded admin and a theme-level app block. To install:

  1. Open your Shopify admin.
  2. Go to Apps → Shopify App Store.
  3. Search for SmartCart by SOAR and click Add app.
  4. Approve the OAuth permissions (read products, read/write cart, read orders).
  5. In the SmartCart admin, click Enable in theme — this activates the app block in your live theme.
Note: On older themes (pre-Online Store 2.0), SmartCart falls back to a script-based install. Email support@soar.studio for help if your theme doesn't support app blocks.

Quickstart

The fastest way to see SmartCart in action:

1. Turn on the free shipping bar

Go to Settings → Free shipping. Enter your shipping threshold (e.g., $75). SmartCart handles the rest — the progress bar appears automatically in your cart drawer.

2. Add your first upsell rule

Go to Rules → New rule. Pick a template:

  • Pair-together: when cart contains Product A, suggest Product B
  • Bundle discount: 10% off when cart has both A and B
  • AOV threshold: when cart total > $X, offer upgrade

3. Preview and publish

Click Preview to see the rule live on a test cart. When happy, hit Publish.

Upsell rules

Rules are the engine of SmartCart. Each rule has a trigger, a target, and an optional incentive.

Rule: "Mug + Hat Pair"
Trigger: cart contains "Insulated Mug"
Target: suggest "Trail Hat"
Incentive: 15% off bundle
Position: below cart items
Max display: once per session

Trigger types

  • Cart contains specific product / variant / SKU
  • Cart total above / below threshold
  • Cart item count > X
  • Customer tag (e.g., only VIPs see this)
  • UTM / referrer source

Free shipping bar

The free shipping progress bar shows customers how close they are to free shipping. Customization options:

  • Threshold: dollar amount for free shipping
  • Progress color: inherits your theme accent by default
  • Message templates: You're $12 away from free shipping! or custom
  • Reward message: shown after threshold is hit — 🎉 You unlocked free shipping!

Gift with purchase

Auto-add a free product to the cart when a condition is met.

Gift rule: "Free sample pack over $50"
Trigger: cart subtotal >= $50
Add: Sample Pack (variant 123)
Pricing: $0 (automatic 100% discount)
Remove if: cart drops below $50

Cart messaging

Show dynamic nudges in the cart based on state. Templates include:

  • Scarcity: Only {inventory} left — order soon
  • Shipping cutoff: Order in {hours}h {minutes}m to ship today
  • Returns reassurance: Free returns within 30 days
  • Trust badges: SSL / Shopify Secure Checkout logos

A/B testing

Growth and Plus plans include built-in A/B testing. For any rule:

  1. Click Duplicate as variant
  2. Edit the variant (different copy, product, incentive)
  3. Set traffic split (default 50/50)
  4. SmartCart tracks conversion rate and incremental AOV per variant
  5. After statistical significance is reached, click Promote winner
Tip: SmartCart uses sequential testing — you can call a winner as soon as significance is reached, no need to wait for a fixed sample size.

AI recommendations

Plus plan unlocks AI-powered pair recommendations trained on your store's order history.

How it works:

  1. SmartCart analyzes 90 days of order data
  2. Identifies products frequently bought together
  3. Builds a product-pair model specific to your store
  4. Serves recommendations in the cart drawer dynamically

The model retrains weekly. You can also exclude specific SKUs from being recommended via Settings → AI exclusions.

Checkout extensions

Shopify Plus merchants on the Plus plan get native Checkout Extension support for post-purchase upsells.

Flow:
Customer completes checkout
→ Thank-you page shows SmartCart upsell
→ One-click add (no re-entering card)
→ Updated receipt sent

Custom styling

SmartCart inherits your theme by default, but you can override:

/* In SmartCart Settings → Advanced CSS */
.sc-upsell-card {
  border-radius: 16px;
  border: 1px solid #e0e0e0;
}
.sc-progress-bar {
  background: linear-gradient(90deg, #dcf24a, #c7e033);
}

Troubleshooting

Upsells aren't showing

  1. Verify the SmartCart app block is enabled in your theme (Online Store → Themes → Customize → App blocks).
  2. Check the rule is published (not in draft).
  3. Make sure the trigger condition actually matches your test cart.
  4. Clear your browser's localStorage — SmartCart respects "max display per session".

Styles look off

Check Settings → Theme compatibility. If your theme uses unusual CSS resets, enable Isolated styling mode and SmartCart will use its own CSS without inheriting the theme.

Still stuck? Email support@soar.studio with your store URL and we'll debug it — usually same business day.
